Database Module - Added in v1.0.1 (Hotfix)

Database connectivity and management layer for the application.

Features:
- Database connection pooling
- Query builder
- ORM compatibility
- Migration management
- Backup handling
- Auto-reconnection on connection loss

Supported Databases:
- PostgreSQL (Primary)
- MySQL
- MongoDB (optional)

Connection Pool Settings:
- Min connections: 5
- Max connections: 20
- Connection timeout: 30s
- Idle timeout: 900s

Migrations:
- Schema version tracking
- Rollback support
- Automatic migration on startup
