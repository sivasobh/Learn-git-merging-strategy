Utility Logger Module

Centralized logging system for the application with multiple
output targets and log levels.

Features:

1. Log Levels
   - DEBUG: Detailed information for debugging
   - INFO: General information about application flow
   - WARN: Warning messages for potential issues
   - ERROR: Error messages for failures
   - FATAL: Critical errors requiring immediate attention

2. Output Targets
   - Console (stdout/stderr)
   - File system with rotation
   - Syslog
   - Third-party services (CloudWatch, Datadog, ELK)

3. Log Format
   - Timestamp: ISO 8601 format
   - Level: DEBUG|INFO|WARN|ERROR|FATAL
   - Logger name: Module name
   - Message: Log message
   - Context: Additional fields (userId, requestId, etc.)
   - Stack trace: For errors with exception details

4. Configuration
   - Log level per environment
   - File rotation (daily, size-based)
   - Log retention (30 days)
   - Async logging for performance
   - Structured logging (JSON format)

5. Features
   - Request logging middleware
   - Error logging with stack traces
   - Performance metrics logging
   - Database query logging
   - API call logging
   - Security event logging
   - Audit trail logging

6. Filtering
   - Filter logs by level
   - Filter logs by module
   - Filter logs by time range
   - Filter logs by context

Usage Examples:
   logger.debug("Debug message")
   logger.info("User logged in", { userId: 123 })
   logger.warn("High memory usage", { memory: "95%" })
   logger.error("Database connection failed", { error: err })
   logger.fatal("System crash", { reason: "OOM" })
