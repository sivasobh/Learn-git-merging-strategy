Utility Helper Functions Module

Collection of utility functions used throughout the application
for common operations and data transformations.

Helper Functions:

1. String Utilities
   - capitalize(str) - Capitalize first character
   - camelCase(str) - Convert to camelCase
   - kebabCase(str) - Convert to kebab-case
   - truncate(str, len) - Truncate string to length
   - slugify(str) - Create URL-friendly slug
   - sanitize(str) - Remove special characters

2. Array Utilities
   - chunk(arr, size) - Split array into chunks
   - flatten(arr) - Flatten nested arrays
   - unique(arr) - Remove duplicate items
   - groupBy(arr, key) - Group items by property
   - sortBy(arr, key) - Sort by property
   - paginate(arr, page, size) - Paginate array

3. Object Utilities
   - merge(obj1, obj2) - Deep merge objects
   - clone(obj) - Deep clone object
   - pick(obj, keys) - Pick specific properties
   - omit(obj, keys) - Omit specific properties
   - isEmpty(obj) - Check if object is empty
   - mapKeys(obj, fn) - Map object keys

4. Date Utilities
   - formatDate(date, format) - Format date string
   - parseDate(str) - Parse date string
   - addDays(date, days) - Add days to date
   - diffDays(date1, date2) - Difference in days
   - isExpired(date) - Check if date is expired
   - getNextMonday() - Get next Monday

5. Validation Utilities
   - isEmail(str) - Validate email format
   - isPhone(str) - Validate phone format
   - isURL(str) - Validate URL format
   - isStrongPassword(str) - Check password strength
   - isEmpty(val) - Check if value is empty

6. Number Utilities
   - round(num, decimals) - Round to decimal places
   - percentage(num, total) - Calculate percentage
   - formatCurrency(num, currency) - Format as currency
   - toHumanReadable(num) - Convert to human readable
